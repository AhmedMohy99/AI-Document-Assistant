# AI Document Assistant

Built a document-aware AI assistant that lets users upload text/PDF content and ask questions in a clean web interface.

## Upwork Portfolio Details
- **Project title:** AI Document Assistant
- **Your role:** AI Engineer & Full-Stack Developer
- **Skills and deliverables:** Next.js, TypeScript, OpenAI API, Tailwind CSS, PDF Processing

## Deploy
1. Upload the folder to GitHub.
2. Import the repo into Vercel.
3. Run `npm install`.
4. Build command: `npm run build`
5. Start command: `npm run start`
